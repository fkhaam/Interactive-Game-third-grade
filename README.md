# رحلة الضرب الفضائية

لعبة تفاعلية لطلاب **الصف الثالث الابتدائي** في مادة الرياضيات، الفصل الرابع: الضرب (١).

- المملكة العربية السعودية – وزارة التعليم – إدارة تعليم شقراء
- المدرسة الابتدائية الثامنة بشقراء
- المعلمة: خلود العتيبي

## محتوى اللعبة
- كوكب الشبكات (٤-١)
- الضرب في ٢ و٤ و٥ و١٠ (٤-٢، ٤-٣، ٤-٥، ٤-٦)
- الضرب في الصفر والواحد (٤-٨)
- خاصية الإبدال
- سباق النجوم: مراجعة سريعة في ٦٠ ثانية

## التشغيل
افتح ملف `index.html` في المتصفح، أو انشر المستودع على Vercel كموقع ثابت (لا يحتاج إلى أي إعدادات بناء).
